# 🏛️ УрФУ × Campus Connect — Концепция нового цифрового фасада университета

> **Конкурсный проект редизайна главного сайта Уральского федерального университета (`urfu.ru`) и студенческой экосистемы `Campus Connect`.**  
> Проект объединяет эстетику света и стекла нового кампуса в Новокольцовском, ролевую UX-архитектуру (**Абитуриент / Студент / Педагог**) и бесшовные кинематографичные переходы.

---

## ✨ Ключевые особенности проекта (UX / UI)

### 1. Ролевая адаптация интерфейса (Role-Based UX)
Сайт отказывается от перегруженного бюрократического дерева разделов и автоматически перестраивает навигацию и контент под конкретную роль пользователя:
* 🎓 **Режим Абитуриента (Стартовый по умолчанию):** встречает гостя без необходимости авторизации. Включает интерактивный калькулятор баллов ЕГЭ, пошаговый трекер поступления (4 шага), промо-лендинг образовательной программы, 3D-карту кампуса и запись на Дни открытых дверей. Внутренние учебные разделы (ДЗ, БРС, расписание пар) скрыты и не создают визуального шума.
* ⚡ **Режим Студента (После входа через УрФУ ID):** скрывает рекламные блоки для поступающих и открывает персональный дашборд: недельную сетку расписания (Пн–Сб), трекер сдачи домашних заданий с прикреплением ссылок на GitHub/Figma, электронную зачётку БРС и ИИ-сервис подбора команды **UrFU TeamUp**.
* 👩‍🏫 **Режим Педагога (После входа преподавателя в УрФУ ID):** формирует персональное расписание только из пар авторизованного преподавателя (по всем его потокам и группам), открывает журнал быстрой проверки лабораторных работ с выставлением баллов в БРС в один клик и конструктор новых заданий для потока.

### 2. Архитектура света и стекла (Glassmorphism)
Дизайн вдохновлен панорамными атриумами нового кампуса УрФУ в Новокольцовском:
* Многослойные полупрозрачные панели (`backdrop-filter: blur(22px) saturate(160%)`) с мягкими внутренними бликами.
* Благородная академическая палитра:
  * **Navy Primary (`#1F2A44`)** — глубокий академический синий для навигации, типографики и акцентов.
  * **Warm Beige (`#E8DCC8` / `#FAF7F2`)** — тёплый светлый тон поверхностей и подложек.
  * **Soft Gold (`#C6A75E`)** — золотой акцент для активных состояний, бейджей и ключевых метрик.

### 3. Адаптивная боковая навигация с Drag & Drop (Слева ↔ Справа)
* Раскрывающаяся боковая панель (**Mini ↔ Full**) с плавным вогнутым вырезом активного пункта меню, который визуально сливается с фоном рабочей области.
* Поддержка **перетаскивания мышью (Drag & Drop)** и кнопки быстрого переключения: пользователь может закрепить панель навигации как **слева**, так и **справа** страницы.

### 4. Интерактивные модули
* 🗺️ **Встроенный 3D-навигатор корпуса (`campusnavigator-mu.vercel.app`)** с переключением масштаба (`75% / 85% / 100%`) и мгновенной подсветкой аудитории по клику из расписания пар.
* 🗓️ **Календарная сетка расписания (Пн–Сб)** с фильтрацией по типам занятий (*Лекции / Лабораторные / Практикум*), чётности недели и персональной выборкой для педагога.
* 🤖 **UrFU TeamUp & GigaChat Помощник** — ИИ-матчинг студентов в проектные команды и сквозной чат-ассистент кампуса.

## 🚀 Быстрый запуск и тестирование ролей
Склонируйте репозиторий или скачайте архив проекта.
Убедитесь, что папка src/ с 5 фотографиями кампуса находится в одной директории с index.html.
Откройте index.html в любом современном браузере (или запустите через Live Server в VS Code / PyCharm).
Как протестировать все 3 роли для жюри:
При открытии сайта вы находитесь в Режиме Абитуриента.
Нажмите «Войти через УрФУ» (или кликните на переключатель 🔒 Студенту / 🔒 Педагогу в верхней панели) — откроется анимированное окно УрФУ ID с кнопками быстрого демо-входа за Студента (Эльдаров Э. Э., гр. РИ-160033) и за Педагога (доц. Соколов А. В. или В. В. Виткин).

## 🎨 Импорт макетов в Figma
Все 11 экранов прототипа полностью готовы к переносу в редактируемые слои Figma (Auto Layout):
Установите плагин и Chrome-расширение html.to.design.
Откройте прототип в браузере, при необходимости закрепите боковое меню кнопкой 📌 и перенесите экраны в режиме Абитуриента, Студента и Педагога прямо на холст Figma.
